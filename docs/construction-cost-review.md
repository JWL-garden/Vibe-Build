# 공사비 데이터 검토·반영 (2026-10-12)

> 기준 파일: `261012_데이터 통합_대출비율 80%·금리 6% 기본값.xlsx` (기준 엑셀 버전 `261012-a`)
> 상태: 코드·테스트 반영 완료, **커밋 전**. 아래 "결정 필요" 3건 확인 후 커밋.
> 검증: `npm run data:check` 오류 0 · 경고 1(기존) / Vitest 21파일 210개 통과 / `tsc --noEmit` 통과

## 1. 검토한 내용

새 엑셀에 공사비 관련 시트가 추가되어 있다.

| 시트 | 내용 | 처리 |
|---|---|---|
| 하우빌드 공사비 | 저층 주택·상가주택 신축 도급 공사비 220건 (VAT 포함, 건설공사비지수로 2026 환산) | **변환·사용** → `lib/data/construction.json` |
| 하우빌드 2026환산 | 위 자료의 권역·연도·층수별 집계표 | 변환 안 함, `constructionCost.test.ts`로 값 대조 |
| 건설공사비지수 | 주거용건물 연도별 지수·보정계수 | 변환 안 함 (보정계수는 공사비 시트에 이미 반영) |
| 빈땅_사업비 | 빈땅 신축 사업비·대출 상환액 (대출 80%·금리 6.0%·20년 원리금균등) | 등록만, 앱에서 사용 안 함 |
| 필지분류·협소필지·토지이용계획·부속지번 | 토지 관련 부가 자료 | 등록만, 사용 안 함 |

기존 시트(건축물대장, 전유공용면적, 주차대수, 용적률완화_주차검토 등)는 T1·T2 값이 261007-b와 같다. 차이는 부동소수 끝자리와 빈 문자열 → null 표기뿐이며, 기준 엑셀을 교체해도 안전하다.

## 2. 반영한 내용

### 2-1. 데이터
- `lib/data/source.json`: 기준 엑셀 경로·버전을 `261012-a`로 변경
- `lib/data/sheetMap.json`: `하우빌드 공사비` 변환 규칙 추가, 나머지 신규 시트는 등록만
- `scripts/check-data.mjs`: 필지 번호가 없는 통계 시트는 T1·T2 존재 검사에서 제외

### 2-2. 계산 (`lib/calc/constructionCost.ts`, 순수 함수)
- 권역·착공연도별 ㎡당 공사비(연면적 기준, 2026 환산) 중앙값, 평당 단가, 공사 기간 중앙값 집계
- 적용 집단: **서울, 착공 2023~2025 (6건)** — ㎡당 **3,023,747원** (엑셀 집계표 5번 표와 일치)
- 표본이 5건 미만이면 같은 권역 전체 기간으로 대체
- 규칙값은 `lib/rules/financeDefaults.ts`의 `constructionCostRule`

### 2-3. 수익성 적용
재건축 신축 단가 `newBuildCostExcel`이 가정값 입력 엑셀에서 비어 있어 실적으로 자동 채운다.

| 구분 | 값 |
|---|---|
| 기준 | 서울 착공 2023~2025 중앙값 3,023,747원/㎡ |
| 보수 (ROI 불리) | 상위 사분위 |
| 낙관 (ROI 유리) | 하위 사분위 |
| 근거 등급 | B (공개자료 기반) |
| 적용 방식 | `max(건물신축단가표 2,055,379원/㎡, 공사비 실적)` |
| 우선순위 | 사용자 입력 > 가정값 입력 엑셀 > 공사비 실적 |

## 5. 한계

- 하우빌드 공사비는 시공사 도급 공사비(VAT 포함)이며 **감리비·부담금 등 간접비가 빠져 있다.**
- 건설공사비지수는 직접공사비 물가 기준이라 시공사 이윤·인력 수급 변동은 반영하지 못한다.
- 실적은 **신축** 자료다. 상부 증축(건식 조립식) 공사비의 직접 근거가 아니다.
- 공사 기간 실적(서울 최근 3년 중앙값 약 9개월)은 재건축 가정 10개월과 비슷하며, 4장에 비교 문장으로 표기된다.
