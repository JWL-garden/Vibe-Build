## 3. 전월세 전환율 (결정 6)

| 구분 | 법정 상한 산식 | 2026-10-08 값 | 근거 법령 |
|---|---|---|---|
| 주택 | min(연 10%, 기준금리 + 연 2%p) | **5.0%** | 주택임대차보호법 제7조의2 · 시행령 제9조 |
| 상가·사무실 | min(연 12%, 기준금리 × 4.5) | **12.0%** | 상가건물 임대차보호법 제12조 · 시행령 제5조 |

| 수익 시나리오 | 주택 | 상가·사무실 |
|---|---|---|
| 보수 | 법정 상한 5.0% | min(시장, 법정 상한) — 시장값 입력 대기 |
| 기준 | 시장 5.625% | 시장 — 입력 대기 |
| 낙관 | 시장 5.625% | 시장 — 입력 대기 |

> 법정 상한(5.0%)이 시장 전환율(5.625%)보다 낮아서, 보수 시나리오는 보증금의 월세 환산액이 더 작게 나온다.

## 4. 임대 사례 (결정 5)

**2026-10-08 수집 결과** (`npm run data:rent`, 당산동6가 연립다세대, 계약일 2025-10-10 ~ 2026-10-03, 202건 — 두 구간 모두 10건 이상이라 영등포구 사례는 섞지 않음)

| 구간 | 사례 수 | 중위 보증금 (월세 계약) | 중위 월세 | ㎡당 월 환산 임대료 — 보수(5.0%) / 기준(5.625%) |
|---|---|---|---|---|
| 전용 0~30㎡ | 177건 (월세 137 · 전세 40, 신규 120 · 갱신 55) | 9,936만원 | 44만원 | 43,921 / 48,257원/㎡·월 |
| 전용 30~60㎡ | 25건 (월세 17 · 전세 8, 신규 20 · 갱신 5) | 5,000만원 | 57만원 | 22,222 / 23,345원/㎡·월 |

> 갱신 계약(인상률 5% 상한 적용)이 함께 들어 있어 시장 신규 임대료보다 낮게 나올 수 있다 — 신규 계약만 쓸지 결정 필요. 관리비는 신고자료에 없어 비어 있다.

- 자료: 서울시 부동산 전월세가 정보 (서울 열린데이터광장 OA-21276, 서비스 `tbLnOpendataRentV`, 국토교통부 전월세 신고자료 기반)
- 범위: 2025-10-09 ~ 2026-10-08, 건물용도 '연립다세대', 전용 60㎡ 이하 → 0~30㎡ / 30~60㎡ 구간별 중위값
- 지역: 당산동6가 (법정동 코드 11600). 구간별 10건 미만이면 영등포구 사례 포함
- 확인된 건수 (전 용도, 2026-10-08 샘플 키 조회): 당산동6가 접수 2025년 1,025건 · 2026년 543건 (오피스텔·단독다가구 포함)
- **채우는 방법**
  1. data.seoul.go.kr에서 일반 인증키 발급 (무료)
  2. `.env.local`에 `SEOUL_OPEN_API_KEY=발급받은키` 추가 (깃에 올라가지 않음)
  3. `npm run data:rent && npm run data:excel`
  - 엑셀 '임대사례' 시트에 직접 입력해도 된다. `data:rent`는 출처가 '서울 열린데이터광장'인 행만 다시 쓴다.
- 월 환산 임대료 = (월세 + 보증금 × 전환율 ÷ 12) ÷ 전용면적 → 구간별 중위값 (`lib/calc/assumptions.ts summarizeRentComps`)

## 6. 값 갱신 방법

1. 상위 폴더 `261008_가정값 입력.xlsx`의 '가정값' 시트에서 보수·기준·낙관·등급·출처를 고친다 (A·B 등급은 자료명·기관·기준일 필수)
2. `npm run data:excel` → `lib/data/inputs/*.json` 갱신 (자동 data:check)
3. `npm test` → `assumptions.test.ts`가 키·단위·순서·범위·출처를 검사
4. 이 문서 2장 표와 `docs/data-changelog.md`를 갱신하고 커밋
