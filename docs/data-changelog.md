# 기준 데이터 변경 이력

기준 엑셀이 바뀔 때마다 맨 위에 새 항목을 추가한다. 최신 버전이 맨 위에 온다.

## 데이터 갱신 절차

1. 새 엑셀을 상위 폴더(`../`)에 둔다. 저장소에는 올리지 않는다(.gitignore `*.xlsx`).
2. `lib/data/source.json`에서 `excelPath`, `version`, `sourceDate`, `note`를 고친다.
   - version 형식: `YYMMDD-a`. 같은 날 두 번째 파일이면 `-b`, `-c` 순서로 붙인다.
3. 새 시트를 쓰려면 `lib/data/sheetMap.json`에 한 줄을 추가한다. 단순한 표는 `builder: "generic"`으로 쓴다.
4. `npm run data:excel`을 실행한다. 변환 후 `data:check`가 자동으로 실행된다. 오류가 있으면 엑셀이나 sheetMap부터 고친다.
5. `npm test`를 실행한다. 엑셀 대조 테스트(excelParity) 결과를 아래 항목에 적는다.
6. `git diff lib/data`로 바뀐 값을 확인하고 이 파일에 기록한 뒤 커밋한다.

### 항목 양식

```
## <version> — <sourceDate>
- 파일: <엑셀 파일명>
- 변경 요약: <source.json note>
- 시트: 추가 / 삭제 / 컬럼 변경
- 바뀐 값: T1·T2 중심 (항목 | 이전 → 이후)
- 영향받는 화면·보고서: <분석 화면 단계, 보고서 장>
- 검증: data:check 오류 n · 경고 n / excelParity 통과 여부
```
