## 0. 한 줄 콘셉트

**"건축주와 함께 검토하는, 투명한 증축 타당성 리포트"**

- 키워드: 신뢰 · 정밀 · 절제된 고급감 · 함께 검토 · 투명한 근거
- 방문자: 건물주(주 사용자), 건설사·건축사(검토자)
- 전달할 인상: 검토를 일방적으로 받는 서비스가 아니라, **건축주가 가정값을 직접 조정하며 결정에 참여하는 서비스**

### 디자인 원칙 3가지
1. **여백과 큰 타이포로 신뢰감을 만든다.** 장식은 줄이고 숫자와 문장이 주인공이다.
2. **주황색은 "건축주가 만지는 곳"에만 쓴다.** 입력, 선택, 결정 지점이 주황이고, 시스템이 계산한 결과는 잉크색·회색이다. 3D의 "기존=회색 / 증축=주황"과 같은 규칙이다.
3. **모든 숫자에는 근거 표기가 붙는다.** "예시 가정값", "샘플 데이터", 법규 근거, 면책 문구를 숨기지 않는다. 이것이 고급스러움의 일부다.

## 1. 색상 팔레트 (주요 5색)

현재 `app/globals.css`의 `@theme` 토큰을 최대한 유지하고, 어두운 섹션용 색 1개만 추가한다.

| 역할 | 이름 | HEX | 사용처 |
|---|---|---|---|
| 기본 글자·강조 | Ink | `#151717` | 본문, 제목, 버튼(기본) |
| **신규** 어두운 섹션 | Deep Slate | `#1E2A32` | 메인 히어로, 메뉴 드로어, 푸터, 통계 섹션 배경 |
| 바탕 | Paper `#FFFFFF` / Mist `#F6F6F4` | 같이 사용 | 페이지 바탕 / 카드·구획 배경 |
| 건축주 참여 포인트 | Accent | `#E0621B` | 입력·선택·결정 요소, 증축분 3D, 핵심 CTA |
| 기존·중립 | Existing Gray | `#8D9494` | 기존 건물, 보조 도형, 비활성 |

보조 토큰(기존 유지): `ink-soft #5c6161`, `ink-faint #9a9f9f`, `line #ededed`, `accent-soft #fdf0e8`

**비율 가이드:** 흰색·Mist 70% / Ink 15% / Deep Slate 10% / Accent 5%

**주의**
- Accent `#E0621B`와 흰색의 명암비는 약 3.5:1이라 **작은 글자에 쓰면 읽기 어렵다.** 큰 글자(18px 이상 굵게), 버튼 배경, 도형, 아이콘에만 쓴다.
- 어두운 배경 위 글자는 흰색 또는 `#F6F6F4`, 보조 글자는 흰색 60~70% 투명도.
- 그라디언트와 네온 색은 쓰지 않는다.

```css
/* app/globals.css @theme 에 추가 */
--color-deep: #1e2a32;
```

## 2. 폰트

> ⚠️ 레퍼런스 사이트의 실제 폰트는 텍스트만으로 확인하지 못했다. 아래는 제안값이다. 확인 방법은 7장 참고.

| 용도 | 제안 서체 | 비고 |
|---|---|---|
| 제목(국문) | **Noto Serif KR** 500·700 (현재 사용 중) | 무게감·신뢰감. 보고서 제목과 통일 |
| 본문·UI·숫자 | **Pretendard** 400·500·600·700 | 한글/영문/숫자가 정돈된 산세리프. 무료(OFL) 웹폰트 |
| 영문 슬로건(대문자) | Pretendard 600, 자간 `0.08em` 이상 | 예: `BEYOND THE STANDARD` 같은 큰 영문 레이어 |
| 대체안 | Noto Sans KR (현재 사용 중) | Pretendard 도입이 번거로우면 유지해도 됨 |

참고: KoPub돋움은 `next/font/google`에 없고, 사용하려면 파일을 내려받아 `next/font/local`로 직접 연결해야 한다. 같은 느낌이면 Pretendard가 설정이 쉽다.

### 크기·행간 (데스크톱 기준 / 모바일은 70~80%)
| 요소 | 크기 | 굵기 | 행간 |
|---|---|---|---|
| 히어로 대형 문구 | 56~72px | Serif 700 | 1.15 |
| 영문 슬로건 | 14~18px, 대문자 | 600 | 1.4 |
| H2 섹션 제목 | 36~40px | Serif 700 | 1.3 |
| H3 | 22~26px | 600 | 1.4 |
| 본문 | 16~17px | 400 | 1.7 |
| 캡션·출처·면책 | 12~13px | 400 | 1.6 |
| 핵심 숫자(KPI) | 48~64px | 700, `tabular-nums` | 1.1 |

공통 규칙: 국문은 `word-break: keep-all`, 자간 `-0.01em`, 숫자는 `font-variant-numeric: tabular-nums`.

**보고서(A4) 주의:** 글꼴·크기를 바꾸면 쪽 나눔이 달라진다(`ReportPage`, `lib/report/paginate.ts`). 본문 10~10.5pt 기준을 유지하고 변경 후 인쇄 미리보기로 확인한다.

## 3. 이미지 스타일

### 사진 톤
- 흐린 날의 부드러운 자연광, 낮은 채도(전체적으로 차분한 중성 톤)
- 소재: 국내 도심의 중소규모 건축물(근린생활, 업무, 다가구), 건물 입면 디테일, 옥상·단면이 보이는 구도
- 인물 사진은 최소화. 쓴다면 도면을 함께 보는 장면처럼 자연스러운 것만 쓴다.
- 레퍼런스처럼 **사진 위에 텍스트 레이어를 올리는 구성**을 쓴다(어두운 오버레이 20~40%).

### 일러스트·3D 스타일
- **자체 3D 매스 모델이 주 비주얼이다.** 기존 건물=회색, 증축분=주황, 일조 사선면=반투명, 주변 건물=흰색.
- 선은 가는 라인 위주의 도면 느낌. 등각투영(isometric) 단면도, 치수선, 화살표를 활용한다.
- 배경은 Mist 또는 Deep Slate의 단색. 그림자는 약하게.
- 만화적 캐릭터, 3D 아이콘 세트, 일반 스톡 악수/회의 사진은 쓰지 않는다.

### 사용 규칙
- 외부 사진은 라이선스가 확인된 것만 사용하고, 레퍼런스 사이트의 이미지·로고·문구는 가져오지 않는다.
- 샘플 건물·주소·실적 수치는 모두 가상 값이므로 **"샘플 데이터" 표기**를 붙인다. 가짜 후기, 가짜 고객사 로고, 가짜 실적은 넣지 않는다.

## 4. 레이아웃 레퍼런스

> 두 사이트 모두 텍스트 구조 기준으로 분석했다. 시각적인 세부(간격, 속도)는 직접 열어 확인하고 보정한다.

| # | 링크 | 참고할 점 | 우리 서비스 적용 |
|---|---|---|---|
| 1 | https://iconplanning.com/ | 메인 화면 구성, 진입 연출 | 랜딩 페이지 (아래 4-1) |
| 2 | https://iconplanning.com/ | 우측 상단 메뉴, 메뉴 소개 섹션 레이아웃과 동작 | 햄버거 드로어, 검색 오버레이 (아래 4-2) |
| 3 | https://www.vesplus.co.kr/portfolios/sales | 전체 폰트, 폰트 크기 위계, 카드 그리드 | 타이포 스케일, 샘플 사례 카드 (아래 4-3) |

### 4-1. 랜딩 (`app/page.tsx`) — 레퍼런스 1
참고한 특징: 로고 인트로 → 큰 문구가 줄별로 나타남 → 전체 화면 배경 이미지·영상 → 4가지 가치 섹션 → 숫자 통계 → 사례 → 소식 슬라이드.

| 순서 | 섹션 | 내용 |
|---|---|---|
| ① | 인트로 | 로고가 1초 안팎으로 나타났다 사라지고 히어로로 전환 |
| ② | 히어로 (Deep Slate) | 큰 문구 줄별 순차 등장 + **주소 입력창** + 샘플 버튼 3개. 배경은 자체 3D 매스가 천천히 회전(mp4 대신 React Three Fiber) |
| ③ | 4가지 가치 | 법규 완화 검토 / 일조·용적률 분석 / 3D 증축 시뮬레이션 / 건축주 참여형 보고서 — 4개 패널, 스크롤 시 하나씩 등장 |
| ④ | 숫자 섹션 | 샘플 사례 기준 결과(+N층, ROI 등)를 스크롤 시 숫자 카운트업. "샘플 데이터" 라벨 필수 |
| ⑤ | 검토 과정 | 주소 입력 → 법규 검토 → 가정값 조정 → 보고서 출력, 4단계 가로 배치 |
| ⑥ | 샘플 보고서 미리보기 | 보고서 표지·요약 페이지를 종이 질감으로 보여줌 |
| ⑦ | 푸터 (Deep Slate) | 면책 문구, 데이터 출처, 문의 |

### 4-2. 메뉴 — 레퍼런스 2
참고한 특징: 우측 상단에 검색, 공유, 햄버거, 로그인 아이콘. 햄버거를 누르면 로고·슬로건·연락처가 있는 패널이 열리고, 대분류가 +/− 아코디언으로 펼쳐진다. 검색은 아래에서 올라오는 오버레이.

| 요소 | 우리 서비스 적용 |
|---|---|
| 우측 상단 | 🔍 주소 검색, 샘플 보기, ☰ 메뉴 (로그인은 불필요) |
| 드로어 상단 | 로고 + 슬로건 + 연락처 |
| 아코디언 대분류 | 서비스 소개 / 검토 단계 / 법규 완화 안내 / 샘플 보고서 / 문의 (+/− 토글) |
| 검색 오버레이 | 주소 입력 + 최근 검토 + 샘플 주소 버튼 |
| 열림 연출 | 오른쪽에서 슬라이드, 배경은 반투명 딤 처리, 450ms |

### 4-3. 샘플 사례·타이포 — 레퍼런스 3
참고한 특징: 영문 대형 제목(PORTFOLIOS) + 국문 소개 문장, 카테고리 라벨, 이미지+제목 카드 그리드. 위계가 분명한 폰트 크기.
- 샘플 사례 S1~S3를 카드 그리드로 노출(이미지 + 제목 + 한 줄 결과). 카드 모서리는 기존 `--radius-card: 1.25rem`.
- 큰 영문 제목 + 작은 국문 설명의 조합으로 위계를 만든다.

### 4-4. 분석·보고서 화면
- 분석 화면: 설계서 2-2의 3단 레이아웃(스텝퍼 / 내용 / 3D 미니뷰) 유지, 위 토큰만 적용.
- 보고서(`/report`): **모션 없음.** 종이 느낌의 A4, 제목은 Serif, 숫자는 크게, 근거는 뒤로. 인쇄(`print:`) 스타일을 우선한다.

## 5. "건축주가 검토에 참여한다"는 인상을 만드는 장치

| 장치 | 구현 아이디어 |
|---|---|
| 직접 조정 | 가정값 패널(슬라이더·숫자 입력)을 화면 중심에 두고, 값을 바꾸면 결과·3D·ROI가 즉시 변경 |
| 내 입력 표시 | 건축주가 바꾼 값에는 주황 점과 "내 가정값" 라벨, [기본값으로] 되돌리기 버튼 |
| 결정 포인트 | 단계마다 "건축주께서 정하실 것" 박스 1개 (예: 완화 시나리오 선택, 공사 기간 선택) |
| 함께 보기 | 보수/기준/낙관 3개 시나리오 비교, 완화 전/후 토글 |
| 말투 | "함께 검토합니다", "건축주님의 조건을 반영했습니다" 같은 협업형 문장. 과장·단정 표현 금지 |
| 보고서 | 표지에 "건축주 입력 조건" 요약을 넣어, 건축주의 조건이 반영된 보고서임을 드러냄 |

### 신뢰 장치
법규 근거 문구, 출처, "예시 가정값" 라벨, 면책 문구, 보수 시나리오·리스크 병기. 좋은 숫자만 강조하지 않는다.

## 6. 모션 가이드

| 효과 | 사양 |
|---|---|
| 기본 이징·길이 | `cubic-bezier(0.2, 0.7, 0.2, 1)`, 400~700ms |
| 텍스트 등장 | 줄 단위 아래→위 페이드, 줄 간 60~80ms 지연 |
| 숫자 카운트업 | 뷰포트 진입 시 1회, 약 1.2초 |
| 드로어·오버레이 | 슬라이드 450ms + 딤 페이드 |
| 스크롤 등장 | 섹션당 1회만 (반복 재생 금지) |
| 접근성 | `prefers-reduced-motion: reduce`이면 모든 모션 제거 |
| 금지 | 보고서·인쇄 화면의 모션, 자동 재생 소리, 과한 패럴랙스 |

성능: 3D 히어로는 저사양에서 정지 이미지로 대체하고, 한글 폰트 용량을 고려해 이미지·폰트를 가볍게 유지한다.

4. 사진·영상 소스의 라이선스.

## 8. Claude Code에 요청할 때 (순서 권장)

각 단계는 "먼저 계획만 보여주고 내가 승인하면 작업해" 방식으로, 단계마다 `npm run dev`로 확인하고 커밋한다.

1. **토큰**: `docs/moodboard.md` 1장 기준으로 `globals.css`에 `--color-deep`을 추가하고 색 사용 규칙(주황=건축주 참여 지점)을 적용할 파일 목록을 보여줘.
2. **폰트**: 2장 기준으로 Pretendard를 `next/font/local`로 적용하고 크기·행간 스케일을 토큰으로 만들어줘. 보고서 쪽 나눔이 깨지지 않는지 확인해줘.
3. **랜딩**: 4-1 순서대로 히어로(주소 입력 포함)부터 만들어줘. 모션은 6장 규칙을 따르고 `prefers-reduced-motion`을 지켜줘.
4. **메뉴**: 4-2대로 우측 드로어와 검색 오버레이를 만들어줘.
5. **샘플 사례**: 4-3대로 S1~S3 카드 그리드를 만들어줘. 모든 수치에 "샘플 데이터" 라벨을 붙여줘.
6. **참여 장치**: 5장 기준으로 가정값 패널에 "내 가정값" 표시와 "건축주 결정 포인트" 박스를 추가해줘.
